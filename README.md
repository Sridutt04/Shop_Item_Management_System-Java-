# 🛒 Shop Item Management System (Java)

## 📌 Project Overview
The Shop Item Management System is a simple Java console-based application that demonstrates the concept of **Encapsulation** in Object-Oriented Programming (OOP).

This project allows you to:
- Create a shop item
- Store item details (name, price, quantity)
- Access item details using getter methods
- Update item quantity using a method

---

## 🚀 Features
- Create a shop item using a constructor
- Private data members (Encapsulation)
- Getter methods to access item details
- Method to update item quantity
- Simple and clear console output

---

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Encapsulation
- Classes and Objects

---

## 💻 How the Program Works

1. The `ShopItem` class contains:
- Private variables: itemName, itemPrice, itemQuantity
- A constructor to initialize values
- Getter methods to retrieve data
- A method `updateQuantity()` to increase quantity
2. The `ShopApp` class:
- Creates an object of ShopItem
- Prints item details
- Updates quantity
- Displays updated quantity

---

## ▶️ How to Run

Step 1: Save the file as
ShopApp.java

Step 2: Compile the program
javac ShopApp.java

Step 3: Run the program
java ShopApp
